## 🚀 How to Run Locally

### 1. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your web browser.

### 2. Build for Production
```bash
npm run build
```
Generates an optimized, self-contained build in the `dist/` directory with all assets included.

## 📁 Key Sections Included

1. **Home (`/`)**: Hero with lab background, no MIT logo, PRN quick pills, and full Team Members section.
2. **01 Chemistry (`/chemistry`)**: Interactive chemical explorer (Methanol, H₂O₂, Glycerol, Distilled Water) with molecular formulas and reaction equations.
3. **02 Procedure (`/procedure`)**: Photographic step-by-step procedure with click-to-zoom lab photos.
4. **03 Diagrams (`/diagrams`)**: Interactive toggle for Process Flow Diagram (PFD) and Functional Block Diagram.
5. **04 Video (`/video`)**: Demonstration video player with lab highlights.
6. **05 Applications (`/applications`)**: Clinical and daily use cases, key advantages, and safety precautions.
7. **06 AI Quiz (`/quiz`)**: Multiple-choice quiz with instant score calculation and detailed explanations.
